# ✨ Daily Spark: Random Quote Generator

A simple, lightweight Django application that serves up a fresh dose of motivation every time you refresh the page. 

## 🚀 Features
* **Randomized Delivery:** Pulls a random quote from a SQLite database.
* **Admin Interface:** Easily add, edit, or delete quotes via Django's built-in admin panel.
* **Clean UI:** A minimalist, centered card design for focus.

## 🛠️ Tech Stack
* **Backend:** Python / Django 5.x
* **Database:** SQLite (Default)
* **Frontend:** HTML5 / CSS3
